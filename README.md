# মেসার্স সোনালী ট্রেডার্স

টঙ্গী, গাজীপুরের চালের পাইকারি আড়তের বাংলা ভাষার ব্যবসায়িক ওয়েবসাইট।

## ওয়েবসাইটের অংশগুলো

- হোমপেজ ও ব্যবসার পরিচিতি
- চালের সম্পূর্ণ ক্যাটালগ
- পাইকারি ও বাণিজ্যিক সরবরাহ
- হোয়াটসঅ্যাপে পাঠানোর অনলাইন অর্ডার ফর্ম
- আমাদের সম্পর্কে ও ব্যবসার পথচলা
- দুটি শাখার ঠিকানা, ফোন ও গুগল ম্যাপ
- ব্যবসায়িক ব্র্যান্ড ও কোম্পানির তালিকা

## GitHub-এ আপলোড

১. GitHub-এ নতুন একটি repository তৈরি করুন। Repository-তে README, `.gitignore` বা অন্য কোনো ফাইল আগে থেকে তৈরি করবেন না।

২. এই প্রজেক্টের পুরো ফোল্ডারটি আপনার কম্পিউটারে রাখুন। `.env` ফাইল কখনও আপলোড করবেন না; এটি নিরাপত্তার জন্য বাদ দেওয়া আছে।

৩. প্রজেক্ট ফোল্ডার থেকে নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "Create Sonali Traders website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

`YOUR-USERNAME` এবং `YOUR-REPOSITORY`-এর জায়গায় আপনার GitHub username ও repository name বসাবেন।

## স্থানীয়ভাবে যাচাই

```bash
npm install
npm run build
```

## গুরুত্বপূর্ণ তথ্য

- ব্র্যান্ডের লোগো `public/logo copy.jpeg` থেকে ব্যবহার করা হয়েছে।
- অর্ডার ফর্মটি সরাসরি WhatsApp বার্তা তৈরি করে।
- চালের দাম ও স্টক পরিবর্তনশীল হওয়ায় নির্দিষ্ট মূল্য দেখানো হয়নি; ফোনে বর্তমান পাইকারি রেট জানানো হবে।
